Technical Framework Methodology

Semantic Vector Embeddings

We pass concatenated job listing text through distilroberta-base to extract dense 768-dimensional embeddings of the special [CLS] classification token, representing global context.

Synthetic Minority Over-sampling

To resolve the severe class imbalance in recruitment fraud datasets, we apply SMOTE directly in the high-dimensional embedding space, creating synthetic minority instances for training.

Multi-Layer Perceptron Head

An MLP Classifier with hidden layers of sizes (128, 64) is trained on the balanced SMOTE embeddings to model non-linear fraud indicators with high generalizability.

Explainable AI (XAI) via SHAP

Using a partition-based SHAP Text Explainer, the system calculates Shapley values for individual tokens, highlighting words that contribute directly to the fraud score.
